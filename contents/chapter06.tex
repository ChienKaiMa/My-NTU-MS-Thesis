Modeling quantum state discrimination as quantum circuits aims to enable
researchers to bypass the difficulty of experimental demonstration.
For example, while acquiring the expertise to design and tune optical devices
demands significant effort, researchers without a dedicated optical laboratory
can readily access quantum computers via cloud services such as IBM Cloud or AWS Braket.

The work by Ref.~\cite{RN87} provides a relevant example, exploring the
discrimination of multiple copies of quantum states using both local operations
and classical communication (LOCC) and collective measurements, without the
explicit introduction of an ancilla qubit.
Their findings indicated a performance advantage of collective measurements
over LOCC for certain states with a limited number of copies (around 4 qubits).
While noise simulations in their work performed well, experiments on real
quantum hardware (IBM's Falcon processor) showed significant deviations,
particularly for the 3-qubit collective measurement case.
Illustrative examples of the quantum circuits they employed for LOCC and
collective measurements are presented in Figure \ref{fig:collective_meas_circuit}.

\subsection{POVM Decomposition to Rank-1 Vectors}
To implement POVMs in quantum circuits for QSD, we decompose each POVM element
\(\Pi_i \in \{ \Pi_i \}_{i=0}^k\) into rank-1 vectors using singular value
decomposition (SVD).
For each \(\Pi_i\), SVD yields \(\Pi_i = U \Sigma V^\dagger\), where
\(\Sigma = \text{diag}(\sigma_j)\) contains singular values \(\sigma_j\).
We construct rank-1 vectors \(\ket{v_j} = \sqrt{\sigma_j} u_j\), where
\( u_j \) is the \( j \)-th column of \( U \), discarding those with
\(\sigma_j < 10^{-4}\).
This reduces the input isometry size for the same isometry synthesis method,
producing simpler circuits with fewer qubits, lower depth, and fewer two-qubit gates.

For example, applying this to an MED POVM for the entangled states in Subsection
\ref{subsec:entangled_states} (\(\ket{\psi_1}, \ket{\psi_2}, \ket{\psi_3}\))
yields four singular values per \(\Pi_i\) (\(i=1,2,3\)), with only two per
element exceeding \(10^{-4}\) (e.g., \(\approx 1.0, 0.3333\)), reducing the
number of rank-1 vectors from 12 to 6.
This produces the circuit metrics in Table \ref{tab:med_circuit_size}, showing that
discarding the elements with smaller \(\sigma_j\) improves circuit simplicity.
The circuits in the table are produced by cosine-sine decomposition (CSD)
for isometries, and haven't been further transpiled or optimized yet.
The circuit depth and the number of two-qubit gates are obtained by the
circuits decomposed with the basis gate set \{u, cx\}.

\subsection{Rank-1 Vectors to Isometry}
To construct an isometry from the rank-1 vectors \(\{ \ket{v_j} \}_{j=1}^m\)
obtained via SVD, we embed them into an orthonormal basis of a larger Hilbert
space, per Naimark's dilation theorem.
This dilates the POVM to a projective measurement in an extended space of
dimension \(d' = 2^{\lceil \log_2 m \rceil}\), enabling efficient circuit synthesis.

The isometry \(V \in \mathbb{C}^{d' \times m}\) is formed by placing each
\(\ket{v_j}\) as a column in the \(j\)-th position of the extended basis,
padded with zeros elsewhere.
This sums outer products: \(V = \sum_{j=1}^m \ket{e_j} \bra{v_j}\), where
\(\ket{e_j}\) is the standard basis vector in the dilated space.

\subsection{Simulation results}

Since we have obtained the circuits, we can run simulations to see if the
circuits actually implement unambiguous quantum state discrimination.
We are also curious about how noise will affect the discrimination results,
and we want to see if smaller circuits work well enough for the states using
more qubits.
We expect the circuits with high process fidelity to run successfully, so we
will show the results together with noisy simulation.



The noise model we apply for the quantum circuits is a depolarizing channel
on every two-qubit gate. Since we use Qiskit for noisy simulation, we follow
Qiskit's definition \cite{qiskitDepolarizing_errorQiskit} of the depolarizing
channel, described as follows:
\begin{align}
    E(\rho) = (1 - \lambda) \rho + \lambda \text{Tr}[\rho] \frac{I}{2^n}
\end{align}
with $0 \le \lambda \le 4^n / (4^n - 1)$,
where $\lambda$ is the depolarizing error param and $n$ is the number of qubits.

The parameters for $\lambda$ span from \(1 \times 10^{-6}\) to \(1 \times 10^{-1}\),
with 3 representative values per order of magnitude (\(1\times\), \(2\times\), and \(5\times\)). This pattern captures typical values within each scale.

We won't simulate some circuits because their circuit depths are too large
from the start.
